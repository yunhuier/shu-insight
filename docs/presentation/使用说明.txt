上大知讯 · HTML 课堂演示稿

1. 先完整解压，再用 Edge 或 Chrome 打开“上大知讯-项目演示.html”。第 2 页截图 notice-screenshot.png 和 HTML 放在同一个文件夹。
2. 方向键、空格或下方按钮翻页。F 全屏，O 目录，P 显示或隐藏讲解提示，M 开关动画。
3. 第 5 页可切换推荐权重，第 6 页可播放聚类示意，第 7 页可逐步查看 RAG 流程。
4. 第 9—11 页用于现场演示交接，顺序为殷宇辉、苏锐、顾嘉禾。
5. 如需现场操作，先按项目原有说明启动网站，再点击“打开本机 Demo”。通知更新和 RAG 问答需要网络，问答还需配置 API Key。
6. 聚类画像在至少打开 10 篇不同文章后启用。相同文章重复点击只计一次。

分享时发送整个压缩包。
